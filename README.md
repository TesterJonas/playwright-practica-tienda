# 🛒 Playwright - Práctica Tienda

Proyecto de automatización E2E para practicar compras en tienda demo usando Playwright + TypeScript.

## 🚀 Tecnologías
- Playwright
- TypeScript
- Page Object Model (POM)

## 📋 Casos cubiertos
- Login
- Agregar al carrito
- Checkout completo
- Validación de precios

## ▶️ Cómo ejecutarlo
```bash
npm install
npx playwright install
npx playwright test
